# Artale 羅密歐與茱麗葉

這是一個可多人一起使用的網頁小工具，用來標記每一層的位置，方便隊伍在遊戲中即時對照。

## 這個網頁可以做什麼

- 建立房間並分享房號給隊友
- 每位玩家用自己的名字加入房間
- 每層可點選任意格子做標記
- 同一位玩家在同一層只會保留一個最終位置
- 支援淺色 / 深色模式切換
- 支援電腦、平板、手機使用

## 如何使用

1. 開啟網頁。
2. 在「玩家名稱」輸入你的名字。
3. 按「創建房間」產生房號。
4. 按房號旁邊的複製圖示，把房號分享給其他人。
5. 按「加入房間」。
6. 在樓層格上點選你想標記的格子。

## 房內操作規則

- 你可以在每一層點選任意格子。
- 如果你在同一層再次點其他格子，系統會自動把你原本的格子換到新格子。
- 你可以按「重置」清空目前標記。
- 如果不使用了，可按「離開房間」。

## 手機與平板使用建議

- 手機畫面較窄時，樓層格可左右滑動。
- 建議使用直向操作，點擊會更準確。
- 若多人同時使用，先確認房號一致再加入。

## 常見問題

### 1. 按了加入房間沒反應

請先確認：

- 已經按「創建房間」
- 有輸入玩家名稱

### 2. 其他人看不到我的標記

- 請確認大家都在同一個房號
- 可嘗試重新加入房間

### 3. 深色模式怎麼切換

點右上角的月亮或太陽圖示即可切換。
