# Artale 羅密歐與茱麗葉

這是一個可多人一起使用的網頁小工具，用來標記每一層的位置，方便隊伍在遊戲中即時對照。

## 這個網頁可以做什麼

- 創建房間並分享房號
- 輸入房號加入隊友的房間
- 每個房間最多 4 位玩家
- 每層可點選任意格子進行標記
- 同一位玩家在同一層只會保留 1 個最終格子
- 可一鍵重置整個房間的標記
- 支援淺色 / 深色模式切換
- 支援電腦、平板、手機（含超小手機）

## 如何使用

1. 開啟網頁。
2. 在「玩家名稱」輸入你的名字。
3. 選擇其中一種方式：
	- 方式 A：按「創建房間」產生新房號。
	- 方式 B：在房號欄輸入（或貼上）隊友提供的房號。
4. 按房號旁邊的複製圖示可快速複製房號（房主常用）。
5. 按「加入房間」。
6. 在樓層格上點選你要標記的位置。

## 房內操作規則

- 你可以在每一層點選任意格子。
- 如果你在同一層再次點其他格子，系統會自動把你原本的格子換到新格子。
- 按「重置」會清空整個房間目前的樓層標記。
- 如果不使用了，可按「離開房間」。

## 手機與平板使用建議

- 手機畫面較窄時，樓層格可左右滑動。
- 平板與手機已做版面調整，可直接操作。
- 建議使用直向操作，點擊更容易對準。
- 若多人同時使用，請先確認大家輸入的是同一個房號。

## 常見問題

### 1. 無法加入房間

請先確認：

- 已輸入有效房號（或先按「創建房間」）
- 有輸入玩家名稱
- 房間尚未滿員（最多 4 人）

### 2. 其他人看不到我的標記

- 請確認大家都在同一個房號
- 可先離開再重新加入房間

### 3. 深色模式怎麼切換

點右上角的月亮或太陽圖示即可切換。
